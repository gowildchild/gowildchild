# Freaking Wildchild (`@gowildchild`) — Open-Source Developer & Protocol Architect

I am **Gunther Voet** (`@gowildchild`) an open-source software developer, systems architect and technical writer based in Belgium. My work focuses on low-power protocols, deterministic cryptography, digital preservation and assistive automation, documented across [autiboi.be](https://autiboi.be) and [GitHub (@gowildchild)](https://github.com/gowildchild). Probably I will be splitting the blog in 2 parts later, one to help neurodivergent people and the other one with technical lingo. 

## Open-Source & Active Software Projects

### Protocols, AI & Cryptography
* **[Existenz](https://github.com/gowildchild/Existenz)** — A sub-milliwatt, 128-bit protocol and mathematical framework mapping human rights and threat vectors into deterministic bitmasks ([Live Simulator](https://gowildchild.github.io/Existenz) · [Portal](https://git.gowildchild.com)).
* **[Existenz.AI](https://amitville.com)** — An AI architecture integrating the *Existenz* protocol as a core reasoning layer, the philosophers stone, live at [amitville.com](https://amitville.com).
* **[BitlifeCrisis](https://github.com/gowildchild/BitlifeCrisis)** — A universal, stateless, sub-milliwatt bitstream context library designed for portability across Python, Berry, Forth, Lua, and eBPF.
* **[SesamID](https://github.com/gowildchild/SesamID)** — A custom Perl-engineered multi-factor authentication platform originally designed in 2007, released in 2011, stolen at 2012.
* **[TACO (Trusted Active Crypto Objects)](https://github.com/gowildchild/TACO)** — A cryptographic perimeter and active object security architecture.

### Web Engines, Monitoring & Utilities
* **[VisualMIX](https://github.com/gowildchild/VisualMIX)** — Universal abstract engine bridging web platforms.
* **[Argorithm](https://github.com/gowildchild/Argorithm)** — Persistent Python monitoring framework.
* **[FooGlass](https://github.com/gowildchild/FooGlass)** — Supply-chain security scanner for active Docker projects, in development.
* **[Project-Saver](https://github.com/gowildchild/Project-Saver)** — A Python archival utility built to preserve browser sessions, code repositories and technical documentation into structured Markdown, raw backups, or PDFs.
* **[AutoMAutist](https://github.com/gowildchild/AutoMAutist)** — A Python digital assistant and dashboard integrating Zigbee and REST APIs to automate daily routines and time-management tasks.

### Standards & Writing
